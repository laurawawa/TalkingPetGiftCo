# Custom Talking Dog Video Launch Kit

This folder contains the starter materials for launching a simple Etsy listing for personalized talking dog videos at a $4.99 intro price.

## Files

- `etsy-listing.md` - ready-to-use Etsy title, description, personalization setup, tags, and listing image plan.
- `customer-order-form.md` - the customer intake form to collect order details.
- `production-workflow.md` - the fulfillment checklist for keeping each order simple and fast.
- `script-templates.md` - reusable 30-45 second message templates.
- `launch-tracker.csv` - a simple spreadsheet-style tracker for the first 20 orders.
- `scripts/generate_listing_images.py` - creates Etsy listing image mockups using the Cookie asset.
- `assets/listing-images/` - generated PNG listing images.

## Launch Offer

- Product: personalized 30-45 second talking dog video
- Price: $4.99 per video
- Delivery: digital file through Etsy messages
- Turnaround: 48-72 hours
- Revision: one small revision included
- Starting capacity: 10 orders per week

## First Step

Use the copy in `etsy-listing.md` to create one Etsy listing, upload the images from `assets/listing-images/`, and paste the customer form from `customer-order-form.md` into the personalization instructions or listing description.
