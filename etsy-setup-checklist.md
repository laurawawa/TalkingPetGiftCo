# Etsy Storefront Setup Checklist

Use this as the step-by-step build list once logged into Etsy.

## 1. Shop Basics

- Create or open Etsy seller account.
- Choose shop name.
- Add shop title: `Custom talking dog videos for sweet, funny gifts.`
- Add shop announcement from `storefront-copy.md`.
- Add shop about section from `storefront-copy.md`.
- Add shop icon or logo.
- Add shop banner.

## 2. Listing

- Create one listing.
- Listing type: digital/custom digital service.
- Title: use `etsy-listing.md`.
- Price: `$4.99`.
- Quantity: start with `10`.
- Processing time: `3 business days` or closest Etsy option.
- Renewal: manual, if available.
- Personalization: enabled and required.
- Photo upload: required if Etsy allows it; otherwise instruct buyers to message photos after checkout.
- Description: use `etsy-listing.md`.
- Tags: use the 13 tags in `etsy-listing.md`.
- Category suggestions to test:
  - Gifts for Pets
  - Pet Gifts
  - Digital Prints / Digital Gifts if Etsy does not offer a pet video category

## 3. Images

Upload in this order:

1. `assets/listing-images/01-main-custom-talking-dog-video.png`
2. `assets/listing-images/02-how-it-works.png`
3. `assets/listing-images/03-occasions.png`
4. `assets/listing-images/04-photo-tips.png`
5. `assets/listing-images/05-style-and-voice.png`
6. `assets/listing-images/06-delivery-and-revisions.png`

## 4. Policies

Add the shop policies from `storefront-copy.md`:

- Delivery
- Revisions
- Cancellations
- Returns and exchanges
- Photo permission
- Content limits

## 5. FAQ

Add FAQ entries from `storefront-copy.md`.

## 6. Saved Replies

Create Etsy saved replies:

- Missing details reply
- Delivery reply

Both are in `storefront-copy.md`.

## 7. Before Publishing

- Preview listing on desktop.
- Preview listing on mobile.
- Confirm price shows `$4.99`.
- Confirm personalization is required.
- Confirm photo instructions are visible.
- Confirm delivery says digital through Etsy messages.
- Confirm one revision is included.
- Confirm no physical shipping promise appears.
